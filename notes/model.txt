Idea for moving counter to state

1. Hardware Level: The Interrupt Controller (Best for Real-Time/Hardware Guarantees)
If you want guaranteed, hard-real-time enforcement that cannot be bypassed or delayed by software execution, the counter must be implemented in the Interrupt Controller (such as the ARM GIC, RISC-V PLIC/CLIC, or x86 APIC) or a custom Hardware Interrupt Throttler block.

Where: In the interrupt controller’s register space (as MMIO-mapped registers).

How it works:

When an interrupt is dispatched to the CPU, a hardware timer is initialized with the "time slice" value.

The timer decrements while the CPU is executing in interrupt context (which the hardware can track by monitoring the interrupt acknowledgment and End-of-Interrupt (EOI) signals).

If the counter reaches zero before the EOI is received, the hardware logic triggers an internal mask signal, disabling the distributor or the CPU interface from forwarding any further interrupts to the processor.
