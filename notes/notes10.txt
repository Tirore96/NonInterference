It does not visibly affect output based on receiving disk interrupts, but it allows the potential for it since it changes state of the natural numbers to the high values that prevent the switches in the pool to be affected. The intention is that it has no public effect, but it is still information leak. Being compositional, we have to prevent this information leak at the border of the sta combinator. We do this by making the state of the loop_and_count parametric, so that the bad_schedule can continue using the natural numbers. We want it to continnue using it because we by definition of being a bad scheduler not determine its scheduling deterministically, as it will change course based on disk interrupts.
