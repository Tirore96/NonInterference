\section{How General the Result Is}\label{sec:generality}

\Cref{thm:main} covers a family of systems; the mechanisation states it with every
parameter quantified (\m{model_sliced_NI}). The public user process and the
scheduler may be any processes that are $\NI$ at \m{public_equiv}, and the private
user process any process that is $\NI$ at \m{private_equiv}.
Sections~\ref{sec:model}--\ref{sec:proof} fixed the output types of the two user
processes to those of the example; the theorem is parametric in them (\code{Opub}
and \code{Opriv}), and in the handler length \code{runtime} and the number
\code{runs} of handler runs per slice. Everything the pool is built around stays
fixed; everything it carries is left open. The side conditions are the expected
ones: the mechanism cannot make a leaking process secure, so each slot is assumed
non-interfering at its own classification, and the theorem says that composing them
through this mechanism leaks nothing further. The output types, the handler length
and the slice size carry no side condition; for the last two, because the slice is
\emph{defined} as $\mathit{runs}\cdot\mathit{runtime}$ and so ends on a handler
boundary by construction.

Two features of the model make this possible. The state update never reads the
\emph{value} a user slot emits, only whether it emitted (the scheduler-output test
inspects the user slots for \code{None} and nothing more), so no user behaviour reaches
the schedule. And the state obligation \m{fv_NI} never mentions the slot processes, so
the hard side condition is unaffected by what fills them.

What stays fixed is the mechanism under study, the three handlers, and the shape of
the pool around it: six slots in a fixed order. The order is hard-wired in the
projections that read the pool's output, and varying the number of user slots would
change the state transition and with it the proof of \m{fv_NI}.

\paragraph{Levels} We have read levels as two. The mechanisation works over an
arbitrary bounded lattice, where a characterised equivalence must also be monotone
downwards (what a level relates stays related below it, and likewise for
unobservability), and $\NI$ quantifies over every level. Every equivalence in the models
treats the bottom level, read as $\Lo$, apart from all others, so the proof's level
case splits are $\ell = \Lo$ against $\ell \neq \Lo$, and the second case covers every
other level of any lattice at once. In particular, the set $\{\Hi\}$ in
$\mathsf{eqmaybe}(\{\Hi\},\doteq)$ stands for all levels other than $\Lo$.
