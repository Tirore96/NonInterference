\begin{abstract}
Interrupt handling is a key part of an operating system, and a source of timing
leaks. Servicing an interrupt takes time from whichever process was scheduled, so an
attacker who watches a public process sees when a handler ran and for how long. If
the interrupt is secret, so is that information. Such leaks arise in several
operating systems \todo{examples, with citations}. We use the process calculus of
Rafnsson et al., whose timing-sensitive non-interference theorems compose, to model
an operating system with interrupt handling as a single process, and prove in Rocq
that ordinary interrupt handling leaks: a secret disk interrupt is observable
through the schedule alone. A non-interfering policy must make \emph{when} secret
handlers run, and for how long, depend only on public events, while \emph{which}
secret handler runs may stay hidden. We model a policy that does so: secret handlers
run only in time slices of fixed length, opened by the public timer handler, and
runs no interrupt claims are filled by a dummy handler. We prove it timing-sensitive
non-interfering for any scheduler and user processes that are themselves
non-interfering. The implementation of this policy is carried out in separate work
\todo{cite X}.
\end{abstract}
